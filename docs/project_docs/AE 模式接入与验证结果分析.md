## AE 模式接入与验证结果分析

在前期工作中，项目已经完成了基于规则校验、启发式 score、中心距离占位模型和在线 score 服务骨架的逐步演进，并初步建立了从 JSON body、特征抽取、模型训练、统一预测接口到在线评分服务的完整技术链路。在此基础上，为进一步向类 SE-fAnoGAN-ES 模型演进，本阶段引入了 AE（Autoencoder）风格占位模型，用以替代此前的中心距离型占位模型。该模型仅使用 `normal` 样本进行训练，通过学习正常样本在特征空间中的重建模式，并以重建误差作为异常分数，从而实现对待测样本的异常检测。

具体实现上，本阶段新增了 `sefanogan_train_ae.py`，用于基于 `sefanogan_features.csv` 中的正常样本训练小型多层感知机自编码器；训练完成后输出 AE 权重文件 `sefanogan_ae_model.pt` 和元信息文件 `sefanogan_ae_meta.json`。同时，在统一预测接口 `sefanogan_predict.py` 中新增 `ae` 模式分支，使系统能够在 `heuristic`、中心距离 `model` 和 AE 三种后端之间进行切换；在在线服务 `nv_valid_server_real.py` 中，AE 模式得以被现有 UNIX socket RPC 调用流程直接复用，因此无需改动外层 harness、规则校验逻辑和 AFL 驱动方式，仅通过环境变量切换即可完成 AE 后端接入。

从离线验证结果看，AE 模型已表现出明显的异常分层能力。以代表性样本为例，正常样本 `seed_ok_0.json` 的重建误差约为 `1.3e-05`，轻中度边界样本 `fuzz_border_2.json` 的重建误差约为 `0.771489`，而强异常样本 `fuzz_bad_4.json` 的重建误差达到 `5176.372559`。这说明 AE 模型已经能够较为清晰地区分正常、边界和异常样本，且这种分层比此前中心距离模型更符合“学习正常模式、通过重建误差进行异常判断”的异常检测思路。

在在线验证方面，本阶段首先完成了 AE 模式下的手工样本联调，验证了在线 score 服务能够正常接收规范化 body、调用 AE 后端完成推理，并按阈值做出通过或拒绝判定。在此基础上，进一步在 `rule_score-only` 场景下开展 AFL 驱动验证。实验结果表明，在平衡种子集 `in/o2oa_body_model_compare` 上，以阈值 `1.0` 运行时，共有 `124` 个样本通过一级规则进入 AE 二级评分，其中 `83` 个样本被二级 score 放行，`41` 个样本被二级 score 拒绝，同时 `body_score_rpc_ok = 124`、`body_score_rpc_fail = 0`。该结果说明 AE 模式不仅能够在单样本场景下提供有效异常分数，而且已经能够在 AFL 批量驱动场景下稳定工作，并产生混合型 pass/reject 分层结果。

从项目阶段性意义看，这一结果标志着系统已经从早期的启发式评分与中心距离占位模型阶段，推进到“小样本神经网络异常检测模型”阶段。与此前模型相比，AE 模型具有更强的非线性表达能力，能够在现有特征空间上学习更复杂的正常模式，因此其结果更接近后续类 SE-fAnoGAN-ES 模型的实现方向。虽然当前 AE 模型仍属于过渡性的占位模型，数据规模和训练样本数量也仍有限，但其已经完成了训练、保存、加载、在线接入和 AFL 场景验证的全链路打通，为下一阶段继续扩充数据集、优化模型结构和进一步向 SE-fAnoGAN-ES 风格模型演进奠定了坚实基础。

因此，当前阶段可以将本项目进展概括为：**已完成 AE 风格占位模型的训练与在线接入验证，建立了从数据集、特征、模型训练、统一预测接口、在线评分服务到 AFL `rule_score-only` 验证的完整异常检测模型链路，并获得了具有实际分层意义的验证结果。**
