# 下一阶段技术推进计划

## 1. 当前阶段结束点

当前阶段已完成从启发式评分、中心距离占位模型到 AE 风格占位模型的阶段性演进，并在 `rule_score-only` 场景下完成了 AE 模型的在线验证和最小 train/val 评估。

因此，下一阶段不再以“证明链路能跑通”为主要目标，而是转向“提升模型可信度与评估规范性”。

## 2. 下一阶段优先级

### 优先级 1：继续扩充数据集
下一阶段最重要的任务是扩充数据集，尤其是：

- 增加真实 AFL 回收样本；
- 增加更多 normal 样本；
- 补充不同异常强度区间的边界样本；
- 完善样本来源和标签说明。

目标是将当前约 30 条数据逐步扩展到约 50 条，并提高 normal 样本覆盖。

### 优先级 2：完善 AE 评估流程
在现有 train/val 基础上，进一步完善：

- 更稳定的 train/val 划分；
- 多阈值对比实验；
- 不同阈值下 pass/reject 平衡分析；
- 更长时长的 `rule_score-only` 验证。

目标是使 AE 模型从“可工作”推进到“有较清晰评估依据”。

### 优先级 3：逐步升级模型结构
在数据规模和验证流程更稳定后，再推进模型结构升级。建议路线为：

- 在当前 AE 基础上做轻量改进；
- 再逐步向更接近类 SE-fAnoGAN-ES 的异常检测网络推进。

## 3. 当前阶段不优先事项

以下事项在下一阶段中不应优先：

- 不优先继续扩展中心距离占位模型；
- 不优先围绕三模式全 compare 脚本做过多优化；
- 不优先直接上复杂 GAN 结构。

## 4. 下一阶段建议起点

如果立即进入下一阶段，推荐从以下顺序开始：

1. 扩充数据集到约 50 条；
2. 重跑 `build_dataset.py / export_features.py / sefanogan_train_ae.py`；
3. 重新生成 train/val 结果；
4. 做 AE 阈值对比；
5. 再决定是否升级模型结构。
