# 下一阶段技术推进计划（状态更新版）

## 1. 当前阶段位置

在上一阶段完成 AE 风格占位模型训练、在线接入和 `rule_score-only` 验证后，当前阶段继续围绕“扩充数据集、规范 AE 评估、明确阈值策略”展开。

截至目前，下一阶段的核心工作已经取得明显进展，项目已从“AE 可运行”推进到“AE 有更大数据支撑、具备更系统阈值分析能力”的状态。

## 2. 已完成事项

### 已完成 1：数据集扩充到 50 条
当前 `sefanogan_dataset.jsonl` 已扩充到 50 条，较上一阶段的 30 条数据有明显提升。新增样本包括：

- 新增 normal 样本 8 条；
- 新增 border 样本 6 条；
- 新增 abnormal 样本 6 条。

这使得当前 AE 训练和验证能够基于更丰富的数据分布开展。

### 已完成 2：重新执行数据与训练链
已完成以下链路重建：

- `build_dataset.py`
- `export_features.py`
- `split_dataset.py`
- `sefanogan_train_ae.py`

并成功生成新的 AE 模型与元信息文件。

### 已完成 3：新的 train/val 评估结果
当前 train/val 统计结果为：

- train_normal_count = 10
- val_normal_count = 5
- val_border_count = 16
- val_abnormal_count = 19

AE 重建误差均值结果为：

- train_normal_recon_mean = 0.004165
- val_normal_recon_mean = 0.112509
- val_border_recon_mean = 1.472059
- val_abnormal_recon_mean = 706.991765

说明当前 AE 模型仍保持清晰的分层关系：

> train_normal < val_normal < val_border << val_abnormal

### 已完成 4：AE 阈值对比实验
已完成阈值 `0.8 / 1.0 / 1.5` 的 `rule_score-only` 对比实验，结果表明：

- 阈值越低，reject 越多；
- 阈值越高，pass 越多；
- AE 在线服务在三组阈值下均保持稳定；
- 当前阶段建议将 `1.0` 作为默认工作阈值。

## 3. 当前进行中的事项

### 进行中 1：将 AE 结果固化为阶段默认配置
当前已初步形成以下默认配置：

- 模型模式：`ae`
- compare 输入：`in/o2oa_body_model_compare`
- 默认阈值：`1.0`

下一步需要继续用该配置作为阶段基线，避免后续实验频繁变更主入口。

### 进行中 2：逐步从“实验能跑”转向“结果可稳定复用”
当前已经具备：
- 数据集
- train/val
- 阈值对比
- 结果文档

下一步需要进一步让这些内容形成更稳定的长期使用入口。

## 4. 下一个优先任务

### 优先任务 1：继续扩 normal 样本
虽然当前数据集已扩到 50 条，但 normal 样本仍然相对不足。下一步最值得优先投入的是：

- 增加更多真实业务风格的 normal body；
- 扩展不同 key / 状态 / 类别组合；
- 让 AE 的正常模式学习更稳定。

### 优先任务 2：继续回收真实 AFL 样本
下一步可继续从日志中回收：

- AE 分数位于 `0.2 ~ 2` 区间的边界样本；
- AE 分数位于 `2 ~ 20` 区间的中高异常样本；

以进一步提高数据集对真实 fuzz 分布的覆盖。

### 优先任务 3：做更长时长的 AE 验证
当前阈值对比基于短时 `rule_score-only` 结果。下一步建议：

- 延长验证时长；
- 继续比较不同阈值下的 pass/reject 平衡；
- 观察是否能得到更稳定的统计结果。

## 5. 当前阶段不建议优先做的事

- 不建议优先回到中心距离模型继续扩展；
- 不建议优先围绕三模式全 compare 脚本做过多优化；
- 不建议在当前数据规模下直接上复杂 GAN 结构。

## 6. 当前阶段结论

综合当前结果，项目下一阶段已经完成“数据扩充 + train/val 评估 + 阈值对比”三项关键工作，AE 模型已从“小样本可运行模型”推进到“具有更大数据支撑和初步系统评估依据的阶段模型”。

下一步的核心方向已经明确：

> 继续扩 normal 样本与真实 AFL 回收样本，并在 AE 默认配置基础上开展更稳定、更长期的验证。
