# 当前阶段最终结论

## 1. 当前阶段总体结论

当前阶段已完成两项关键目标：

1. 建立稳定默认基线；
2. 在默认基线基础上验证真实 AFL 中间层增强路线是否有效。

经过数据集构建、AE 模型训练、短时长验证、长时长验证、稳定性分析以及批量重复实验对比，当前项目已经从“实验可运行”推进到“实验系统可复现、结果可比较、结论可固化”的阶段。

---

## 2. 默认基线结论

当前推荐的默认项目基线为：

- `156 rows + AE + threshold=1.0 + rule_score-only`

该基线的作用是：

- 作为当前项目长期引用的标准配置；
- 作为后续汇报、材料撰写和结果复现的主要口径；
- 作为后续增强实验和模型升级实验的对照基线。

在 3 次重复实验下，`baseline_156` 的平均结果为：

### 训练侧平均结果
- train_normal_mean = 0.034274
- val_normal_mean = 0.062106
- val_border_mean = 5.263978
- val_abnormal_mean = 456.089910

### 验证侧平均结果
- 20 秒验证：pass = 79.00，reject = 42.33
- 60 秒验证：pass = 93.00，reject = 61.33
- RPC 故障：0

说明默认基线在训练侧和验证侧都具有稳定性，适合作为当前项目的标准基线。

---

## 3. 增强版实验配置结论

当前增强版实验配置为：

- `182 rows + AE + threshold=1.0 + rule_score-only`

该配置是在默认基线 `156 rows` 基础上，引入两轮真实 AFL 中间层样本后形成的增强版本，主要用于验证：

- 真实中间层样本是否能增强边界层建模；
- 增强后是否仍能保持整条链路稳定。

在 3 次重复实验下，`enhanced_182` 的平均结果为：

### 训练侧平均结果
- train_normal_mean = 0.032222
- val_normal_mean = 0.055160
- val_border_mean = 3.712541
- val_abnormal_mean = 168.484067

### 验证侧平均结果
- 20 秒验证：pass = 78.33，reject = 39.00
- 60 秒验证：pass = 91.33，reject = 58.33
- RPC 故障：0

说明增强版实验配置在训练侧和验证侧同样保持稳定，证明“真实 AFL 中间层增强”路线有效。

---

## 4. 默认基线与增强版实验配置的关系

当前项目建议采用“两层配置”方式管理：

### 默认基线
- `156 rows + AE + threshold=1.0 + rule_score-only`

定位：
- 标准项目口径
- 长期引用基线
- 后续实验对照组

### 增强版实验配置
- `182 rows + AE + threshold=1.0 + rule_score-only`

定位：
- 边界层增强实验口径
- 真实中间层样本增强验证配置
- 后续研究扩展的候选版本

不建议当前直接用 `182 rows` 替代 `156 rows` 作为唯一默认配置，原因是：

1. `156 rows` 更干净，阶段口径更统一；
2. `156 rows` 更适合作为长期稳定对照基线；
3. `182 rows` 的主要价值在于证明增强路线可行，而不是取代默认基线。

## 7. 当前建议

当前建议如下：

1. 默认项目口径统一使用 `156 rows + AE + threshold=1.0 + rule_score-only`；
2. 需要体现真实 AFL 中间层增强效果时，使用 `182 rows + AE + threshold=1.0 + rule_score-only`；
3. 暂停继续扩样本，避免边际收益进一步下降；
4. 下一阶段优先围绕现有两套配置开展结果使用、对比分析和必要升级决策。
