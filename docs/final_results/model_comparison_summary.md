# 中心距离模型与 AE 模型对比总结

## 1. 对比目的

为评估项目中二级 score 后端从“几何占位模型”向“神经网络异常检测模型”演进的必要性，本阶段对两类模型在相同工程框架下进行了对比验证。对比对象包括：

- 中心距离占位模型（placeholder_center_distance）
- AE 风格占位模型（small_autoencoder）

两者均基于相同的特征抽取模块、统一预测接口和在线 score 服务运行，并在 `rule_score-only` 场景下进行 AFL 驱动验证。

## 2. 中心距离模型结果

中心距离模型在平衡种子集 `in/o2oa_body_model_compare` 上的 `rule_score-only` 验证结果为：

- body_rule_pass = 120
- body_rule_reject = 306
- body_score_pass = 112
- body_score_reject = 8
- body_score_rpc_ok = 120
- body_score_rpc_fail = 0

该结果表明，中心距离模型已能够对通过一级规则的样本进行二级 score 处理，并产生一定的 pass/reject 分层结果。但整体上看，其筛选倾向偏宽松，对通过一级规则后的样本拒绝数量较少。

## 3. AE 模型结果

AE 模型在相同平衡种子集上的 `rule_score-only` 验证结果为：

- body_rule_pass = 124
- body_rule_reject = 318
- body_score_pass = 83
- body_score_reject = 41
- body_score_rpc_ok = 124
- body_score_rpc_fail = 0

同时，在 AE 模式的分数分布观测中，获得如下分位数结果：

- p10 = 0.0004590
- p25 = 0.0044423
- p50 = 0.7445881
- p75 = 1.3951347
- p90 = 20.5720158

当前验证采用阈值 1.0，可在平衡种子集上产生明显的混合型 pass/reject 结果。

## 4. 对比分析

从结果上看，中心距离模型和 AE 模型都已经具备在线服务能力，并可在 AFL 驱动场景下完成二级 score 处理；但二者在筛选特性上存在明显差异：

1. **中心距离模型更宽松**  
   在通过一级规则的样本中，中心距离模型放行比例较高，仅拒绝少量样本，说明其更偏向几何距离意义下的粗粒度筛选。

2. **AE 模型更敏感**  
   AE 模型拒绝样本数量明显高于中心距离模型，说明其对异常模式、结构扰动和特征耦合变化具有更强响应能力，更符合异常检测模型的预期行为。

3. **AE 模型更接近后续目标方向**  
   中心距离模型本质上仍属于静态几何模型，而 AE 模型已具备“学习正常模式并以重建误差衡量异常程度”的神经网络特征，因此更接近项目后续拟推进的类 SE-fAnoGAN-ES 模型方向。

## 5. 阶段结论

综合来看，中心距离模型适合作为前期工程占位和小样本快速验证模型，而 AE 模型则代表项目向神经网络异常检测模型演进的关键过渡阶段。当前 AE 模型已经完成训练、保存、加载、在线接入和 AFL 验证，并在 `rule_score-only` 场景下取得了具有实际意义的混合型筛选结果。

因此，本阶段可以形成如下结论：

> 项目已完成从启发式评分、中心距离占位模型到 AE 风格占位模型的阶段性演进，并证明 AE 模型在相同工程框架下相较于中心距离模型表现出更强的异常敏感性，具备作为后续类 SE-fAnoGAN-ES 模型过渡方案的可行性。
