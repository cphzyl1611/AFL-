# AE 模型训练/验证集评估结果

## 1. 数据划分方式

为避免训练与验证完全混合，本阶段对当前 `sefanogan_dataset.jsonl` 做了最小 train/val 划分：

- 训练集：仅包含 `normal` 样本，共 4 条
- 验证集：包含剩余 `normal` 样本、全部 `border` 样本和全部 `abnormal` 样本，共 26 条

其中验证集构成为：

- val_normal = 3
- val_border = 10
- val_abnormal = 13

## 2. AE 训练结果

使用训练集中的 4 条 `normal` 样本训练小型 Autoencoder 后，模型在训练集上的平均重建误差为：

- train_normal_recon_mean = 0.000007

这说明 AE 能够较充分地学习训练集中正常样本的特征模式。

## 3. 验证集评估结果

在验证集上，不同类别样本的平均重建误差如下：

- val_normal_recon_mean = 0.263921
- val_border_recon_mean = 3.749296
- val_abnormal_recon_mean = 658.628209

同时，各类样本误差范围如下：

### val_normal
- min = 0.192462
- max = 0.305158

### val_border
- min = 0.058911
- max = 13.968205

### val_abnormal
- min = 4.396499
- max = 3130.012451

## 4. 结果分析

从验证结果看，AE 模型已在当前小样本条件下形成较明显的误差分层：

1. 训练正常样本误差极低，说明模型已能学习训练集中的正常模式；
2. 验证正常样本误差仍保持在较低水平，说明模型对未参与训练的正常样本仍具有一定泛化能力；
3. 边界样本误差明显高于验证正常样本，说明 AE 对结构扰动和边界变异已有一定敏感性；
4. 异常样本误差远高于前两类样本，说明 AE 模型已能够较明显地区分异常模式。

## 5. 阈值说明

当前 AE 在线验证阶段采用阈值 `1.0`。结合本次 train/val 结果看：

- 该阈值明显高于验证正常样本均值 `0.263921`
- 同时低于边界样本均值 `3.749296`

因此，阈值 `1.0` 具备明确的数据支撑，可视为当前阶段 AE 模型的工作阈值。后续若继续优化，可进一步结合更大规模验证集对阈值做系统标定。

## 6. 阶段结论

本次 train/val 划分结果表明，AE 模型不仅已经完成训练、加载和在线接入，而且在最小验证集条件下已经形成较清晰的正常 / 边界 / 异常误差分层。这说明项目当前已从“可运行模型”推进到“具有初步验证能力的异常检测模型”阶段。
