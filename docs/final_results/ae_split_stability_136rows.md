# AE 136条数据集多次划分稳定性结果

## 1. 实验目的

为验证当前 136 条数据集下 AE 模型的分层能力是否依赖于单次随机划分，本阶段使用不同随机种子对 `train/val` 进行多次划分，并分别训练 AE 模型，观察验证集上的正常 / 边界 / 异常误差均值关系。

## 2. 实验设置

- 数据集规模：136 条
- 模型模式：ae
- 划分脚本：`split_dataset.py`
- 训练脚本：`sefanogan_train_ae.py`
- 随机种子：
  - 20260319
  - 20260320
  - 20260321

## 3. 结果汇总

| seed | train_normal_mean | val_normal_mean | val_border_mean | val_abnormal_mean |
|---|---:|---:|---:|---:|
| 20260319 | 0.035105 | 0.071338 | 3.969512 | 508.473632 |
| 20260320 | 0.032893 | 0.109000 | 6.388015 | 611.684716 |
| 20260321 | 0.032967 | 0.068621 | 4.862526 | 463.666060 |

## 4. 结果分析

从三次不同随机划分的结果看，AE 模型在每次实验中都保持了相同的分层顺序：

> val_normal_mean < val_border_mean < val_abnormal_mean

这说明当前 136 条数据集下，AE 模型的正常 / 边界 / 异常分层并非偶然依赖于某一次 train/val 划分，而是已表现出一定的稳定性。

同时可以看到：

- `val_normal_mean` 始终保持在较低范围；
- `val_border_mean` 始终显著高于 `val_normal_mean`；
- `val_abnormal_mean` 始终远高于前两类样本。

## 5. 结论

多次随机划分结果表明，当前 `136 rows + AE` 配置下的分层能力具有初步稳定性。结合阈值对比、短时长验证和长时长验证结果，可以进一步支持以下结论：

> `136 rows + AE + threshold=1.0 + rule_score-only`
>
> 可作为当前项目默认验证基线，并具备阶段性稳定性支撑。
