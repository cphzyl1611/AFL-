# AE 156条数据集多次划分稳定性结果

## 1. 实验目的

为验证当前 156 条数据集下 AE 模型的分层能力是否依赖于单次随机划分，本阶段使用不同随机种子对 `train/val` 进行多次划分，并分别训练 AE 模型，观察验证集上的正常 / 边界 / 异常误差均值关系。

## 2. 实验设置

- 数据集规模：156 条
- 模型模式：ae
- 划分脚本：`split_dataset.py`
- 训练脚本：`sefanogan_train_ae.py`
- 随机种子：
  - 20260319
  - 20260320
  - 20260321

## 3. 结果汇总

| seed | train_normal_mean | val_normal_mean | val_border_mean | val_abnormal_mean |
|---|---:|---:|---:|---:|
| 20260319 | 0.037827 | 0.073306 | 3.577930 | 398.261070 |
| 20260320 | 0.024601 | 0.088393 | 6.791559 | 269.022717 |
| 20260321 | 0.041753 | 0.043257 | 4.116919 | 287.413081 |

## 4. 结果分析

从三次不同随机划分的结果看，AE 模型在每次实验中都保持了相同的分层顺序：

> val_normal_mean < val_border_mean < val_abnormal_mean

这说明当前 156 条数据集下，AE 模型的正常 / 边界 / 异常分层并非偶然依赖于某一次 train/val 划分，而是已表现出一定的稳定性。

## 5. 结论

多次随机划分结果表明，当前 `156 rows + AE` 配置下的分层能力具有稳定性。结合短时长验证、长时长验证和阈值 1.0 的结果，可以支持以下结论：

> `156 rows + AE + threshold=1.0 + rule_score-only`
>
> 可作为当前 normal 扩充阶段结束时的稳定默认基线。
