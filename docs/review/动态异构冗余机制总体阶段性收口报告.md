# 动态异构冗余机制总体阶段性收口报告

## 1. 背景与目标

本报告对当前动态异构冗余机制阶段性成果进行总体收口，覆盖 O2OA 主平台与 Flowable 第二平台。

本阶段目标不是继续扩大实验，也不是修改正式 profile，而是明确：

- 已经完成哪些动态二阶段机制验证；
- O2OA 与 Flowable 的能力边界分别是什么；
- 当前可以对外交付的工程结论是什么；
- 当前仍不能声称什么；
- 后续若要推进到完整多平台动态异构冗余，还需要补齐哪些工作。

本报告未修改 AFL++ 主链，未修改正式 `o2oa_default` profile，未修改正式 `flowable_v2` profile。

## 2. 动态异构冗余机制定义

本项目中的动态异构冗余机制指：

1. 使用 AE 作为第一阶段判定器；
2. 通过 `t_low / t_high` 将输入动态划分为低风险、高风险和灰区；
3. 低风险样本直接通过，高风险样本直接拒绝；
4. 灰区样本进入 second stage；
5. second stage 可由不同机制承担，例如 GAN online 或 local rule；
6. 当增强路径不可用时，应保留可解释的降级路径；
7. 输出必须能记录 `stage`、second stage 来源、RPC 状态和 HTTP smoke 结果。

“动态”体现在运行时按 AE score 分区调度；“异构”体现在 second stage 使用不同于 AE 的判定机制；“冗余”体现在灰区样本不是只依赖单一 AE 阈值，而是进入第二判定路径。

## 3. O2OA 完成情况

O2OA 当前可以表述为：

> O2OA AE + GAN online second stage 动态异构冗余闭环已完成。

已完成内容：

- AE + rule fallback 轻量动态冗余；
- AE + GAN online second stage 最小闭环；
- 一体化 smoke；
- GAN threshold 离线扫描；
- threshold=1.0 与 threshold=1.2 在线 smoke 对比；
- 固定灰区样本回放；
- 阈值策略决策。

正式 `integration/platform_profiles/o2oa_default.json` 保持：

- `t_low=0.8`
- `t_high=1.5`
- `enable_second_stage=true`
- `second_stage_type=gan`
- `second_stage_endpoint=unix:///tmp/nv_valid_gan.sock`
- `second_stage_threshold=1.0`

阈值策略结论：

- `1.0` 是当前正式默认 second stage 阈值；
- `1.2` 仅作为下一轮候选阈值；
- 不直接修改正式 O2OA profile；
- 不能声称 `1.2` 是最优阈值。

## 4. Flowable 完成情况

Flowable 当前可以表述为：

> Flowable AE + local rule second stage 真实服务 smoke 已通过。

已完成内容：

- Flowable-AE v2；
- Flowable 灰区样本扫描；
- 固定灰区样本 second stage probe；
- Flowable REST 通过 Tomcat Docker 启动；
- `holidayRequest` 流程部署并可启动；
- Flowable second stage 真实服务 smoke。
- Flowable 专用 `flowable_rule_v1` 固定回放、多轮真实 smoke、扩样本与多流程 key 覆盖验证。

正式 `integration/platform_profiles/flowable_v2.json` 保持：

- `t_low=5.8`
- `t_high=6.3`
- `enable_second_stage=false`
- `second_stage_type=rule`
- `second_stage_threshold=1.0`

- `/tmp/flowable_v2_second_stage_probe.json`
- `enable_second_stage=true`

- 不配置 O2OA GAN
- 不替代正式 profile

## 5. O2OA 与 Flowable 的能力差异

| 能力 | O2OA | Flowable |
| --- | --- | --- |
| AE 第一阶段 | 已完成 | 已完成，Flowable-AE v2 |
| 灰区动态调度 | 正式 profile 已启用 | 临时 probe profile 已验证 |
| rule fallback / local rule | 已验证 | 已完成真实服务 smoke |
| GAN online second stage | 已完成，`gan_rpc` 已出现 | 未完成 |
| second stage threshold 定标 | 已完成 O2OA 离线、在线、固定回放 | 未完成 Flowable 阈值定标 |
| 固定灰区样本回放 | 已完成 | 已完成最小 probe |
| 真实服务 smoke | 已完成 | 已完成 local rule second stage smoke |
| 正式 profile 是否启用 second stage | 是 | 否 |

因此，O2OA 是完整的 AE + GAN online second stage 动态异构冗余闭环；Flowable 是 AE + local rule second stage 的真实服务 smoke 通过，仍未进入 Flowable GAN online。

## 6. 当前可交付结论

当前总体验收口径建议为：

> 本阶段已完成 O2OA 主平台 AE + GAN online second stage 动态异构冗余闭环；已完成 Flowable 第二平台 AE + local rule second stage 真实服务 smoke。多平台动态二阶段机制已经完成阶段性验证：O2OA 覆盖 GAN online 路径，Flowable 覆盖 local rule second stage 真实服务路径。当前仍不声称 Flowable GAN online 已完成，也不将 O2OA GAN 直接迁移到 Flowable。

可以声称：

- O2OA AE + GAN online second stage 动态异构冗余闭环完成；
- O2OA 正式默认 second stage threshold 仍为 `1.0`；
- O2OA threshold `1.2` 是下一轮候选，不是正式默认；
- Flowable AE + local rule second stage 真实服务 smoke 通过；
- Flowable 专用 `flowable_rule_v1` 已完成扩样本与多流程 key 覆盖验证；
- Flowable 专用 `flowable_rule_v1` 可进入正式启用候选评审；
- Flowable 正式 profile 仍保持 `enable_second_stage=false`；
- 多平台动态二阶段机制已完成阶段性验证。

## 7. 当前不能声称的内容

不能声称：

- GAN 效果优于 rule fallback；
- O2OA threshold `1.2` 是最优阈值；
- Flowable GAN online 已完成；
- O2OA GAN 可以直接迁移到 Flowable；
- Flowable 正式 profile 已启用 second stage；
- 完整多平台动态异构冗余全部完成；
- 当前结果具备充分统计显著性；
- Flowable 已完成独立 GAN、阈值定标和标签评估。

## 8. 后续工作路线

建议后续路线：

1. 保持 O2OA 正式默认 threshold=`1.0`，继续把 `1.2` 作为候选扩样本验证；
2. 为 O2OA 扩充灰区 valid / invalid 标签集，补充覆盖收益、延迟和稳定性指标；
3. 保持 Flowable 正式 `flowable_v2.json` 暂不启用 second stage；
4. 为 Flowable 固化更大规模灰区样本；
5. 建立 Flowable valid / invalid 标签集；
6. 对 Flowable local rule second stage 做阈值定标；
7. 如需 Flowable GAN，必须训练或确认 Flowable 域 GAN，不直接复用 O2OA GAN；
8. Flowable GAN 完成独立离线扫描、固定回放和真实 smoke 后，再讨论完整多平台动态异构冗余结论；
9. 最终多平台结论需要 O2OA 与 Flowable 在各自正式策略下均完成可复核、可重复的 second stage 验证。

## 10. 总体阶段性结论

本阶段总体结论为：

> 动态异构冗余机制已经完成阶段性总体收口。O2OA 主平台完成 AE + GAN online second stage 动态异构冗余闭环；Flowable 第二平台完成 AE + local rule second stage 真实服务 smoke，并通过 `flowable_rule_v1` 扩样本与多流程 key 覆盖验证，现可进入正式启用候选评审。多平台动态二阶段机制已完成阶段性验证，但 Flowable-GAN、Flowable 正式 profile 启用、跨平台 GAN 迁移和完整多平台动态异构冗余仍需后续独立工作支撑。
