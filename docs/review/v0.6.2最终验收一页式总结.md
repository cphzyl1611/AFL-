## 4. AE v1 与 fAnoGAN candidate 结论

- AE v1 仍为主二阶段判定机制；
- fAnoGAN candidate 在线路径可运行，多轮短时 evidence 中无 scoring error；
- fAnoGAN candidate 推理成本较高，未替代 AE v1；
- 当前不宣称完整 SE-fAnoGAN-ES，也不宣称完整 GAN/fAnoGAN。

## 5. API / MCP prototype 状态

- lightweight API prototype 位于 `integration/api_server.py`；
- MCP-like adapter prototype 位于 `integration/mcp_adapter.py`；
- 二者均为本地原型，不等同于完整平台级 HTTP/RPC 网关或完整 MCP Server；
- 不执行任意 shell，不读取任意路径，不访问真实 Alfresco 服务。
