# 动态异构冗余机制阶段性最终结论

## 1. 结论摘要

截至当前版本，O2OA 范围内的动态异构冗余机制已经完成阶段性工程闭环；Flowable 已完成 AE + local rule second stage 真实服务 smoke，但仍未进入 Flowable-GAN 路径。

可以交付的机制结论是：

- O2OA AE + rule fallback 轻量动态冗余已经完成；
- O2OA AE + GAN online second stage 最小闭环已经完成；
- O2OA 一体化 smoke 已完成；
- O2OA 三种模式效果对比已完成：AE-only、AE + Rule fallback、AE + GAN online；
- Flowable AE + local rule second stage 真实服务 smoke 已通过，正式 `flowable_v2.json` 仍保持 `enable_second_stage=false`；
- 相关代码与证据已提交并推送到 `origin/public-release`，三模式效果对比对应提交为 `f1c0f4ed0b76592a354c89d72c0cd30becc514f9`。

必须保留的结论边界是：

- 机制完成不等于效果优势已证明；
- 本阶段不能声称 GAN online 优于 rule fallback；
- 本阶段不能声称 Flowable GAN online 已完成；
- 本阶段不能声称 O2OA GAN 可以直接迁移到 Flowable；
- 本阶段不能声称完整多平台动态异构冗余全部完成。

## 2. 已完成范围

### O2OA AE + rule fallback

已完成正式 O2OA profile 下的灰区调度与降级路径验证。GAN 服务不可用时，灰区样本能够按设计进入本地 rule fallback，并产生 `second_pass` 或 `second_reject` 阶段结果。

### O2OA AE + GAN online second stage

已完成 GAN online second stage 最小闭环。正式 O2OA profile 保持 `t_low=0.8`、`t_high=1.5`、`enable_second_stage=true`，灰区样本能够进入 GAN RPC 路径，并出现 `second_stage_source=gan_rpc`。

### 一体化 smoke

一体化 smoke 已满足：

- HTTP `200`；
- `rpc_fail_total=0`；
- 出现 `BODY_DECISION_DBG`；
- 出现 second stage 阶段分布；
- GAN online 验证中出现 `second_stage_source=gan_rpc`。

### 效果对比

已完成 O2OA 三种模式对比：

- AE-only；
- AE + Rule fallback；
- AE + GAN online。

每种模式运行 3 次，每次 20 秒。三组任务均返回 HTTP `200`，`rpc_fail_total=0`，未记录 crash/hang。

## 4. 效果对比摘要

三种模式的对比结果如下：

| 模式 | 次数 | HTTP 200 次数 | 平均 pass | 平均 reject | second_pass 总数 | second_reject 总数 | GAN RPC 总数 | rule fallback 总数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| AE-only | 3 | 3 | 80.67 | 62.67 | 0 | 0 | 0 | 0 |
| AE + Rule fallback | 3 | 3 | 98.33 | 44.33 | 69 | 0 | 0 | 69 |
| AE + GAN online | 3 | 3 | 89.67 | 52.00 | 43 | 27 | 70 | 0 |

结果说明：

- AE-only 不触发 second stage，所有 pass/reject 均来自 AE 阈值；
- AE + Rule fallback 能触发灰区 second stage，并在 GAN 不可用时进入 rule fallback；
- AE + GAN online 能触发 GAN RPC，并产生 `second_pass` 与 `second_reject`；
- 本次小样本中 GAN online 的 reject 倾向高于 rule fallback，表现为更严格；
- 更严格不等于更优，本阶段缺少真值标注、阈值定标和统计显著性验证。

## 5. 最终可交付口径

建议对外或阶段验收时使用以下口径：

> 本阶段已完成 O2OA 范围内的 AE 一阶段判定、灰区动态调度、rule fallback 降级路径、GAN online second stage 最小闭环，以及 AE-only / AE + Rule fallback / AE + GAN online 三模式小样本效果对比。Flowable 已通过临时 probe profile 完成 AE + local rule second stage 真实服务 smoke，正式 `flowable_v2.json` 仍保持 `enable_second_stage=false`。现有证据支持“O2OA AE + GAN online second stage 动态异构冗余闭环完成”和“Flowable AE + local rule second stage 真实服务 smoke 通过”。效果对比显示 GAN online 在 O2OA 小样本中更严格，但不能据此证明其优于 rule fallback；Flowable-GAN 和完整多平台动态异构冗余仍未完成。

不应使用以下口径：

- “GAN online 效果优于 rule fallback”；
- “Flowable GAN online 已完成”；
- “O2OA GAN 可以直接迁移到 Flowable”；
- “完整多平台动态异构冗余全部完成”；
- “当前小样本对比具有统计充分性”。

## 6. 后续工作建议

后续如需把结论从“机制闭环”推进到“效果优势成立”，建议补齐：

1. 建立带真值标注的 O2OA body 样本集，覆盖正常、灰区、异常、高风险结构与业务字段变体；
2. 对 AE、rule fallback、GAN online 分别做阈值定标，记录误放、误拒、灰区分流比例；
3. 扩大重复次数和时长，进行显著性检验，避免基于 3 次 20 秒任务给出强结论；
4. 增加覆盖收益、异常发现率、稳定性、延迟开销等指标，不只比较 pass/reject；
5. 固化 GAN online 服务启动、健康检查和失败降级流程；
6. 在 Flowable profile 正式启用、Flowable-GAN、阈值定标和标签评估完成后，再提升 Flowable 结论；
7. 完整多平台动态异构冗余结论应在 O2OA 与 Flowable 均完成正式 profile、独立 second stage 和效果对比后再给出。

## GAN second stage 阈值策略结论

O2OA AE + GAN online second stage 已经完成机制闭环，并已完成离线阈值扫描、threshold=1.0 与 threshold=1.2 在线 smoke 对比、固定灰区样本回放三类验证。

当前阈值策略收口如下：

- threshold=1.0 仍作为 O2OA 正式 profile 的保守默认策略；
- threshold=1.2 作为下一轮扩样本验证的平衡候选策略；
- 当前不修改 `integration/platform_profiles/o2oa_default.json`；
- threshold=1.2 在固定回放中降低 valid 误拒，但同时增加 invalid 误放；
- 当前不能证明 threshold=1.2 是最优阈值；
- 当前不能证明 GAN online 效果优于 rule fallback；
- Flowable 已完成临时 probe profile 下的 AE + local rule second stage 真实服务 smoke；
- Flowable-GAN、Flowable 正式 profile 启用 second stage 和完整多平台动态异构冗余仍未完成。

## 7. 阶段性结论

本阶段可以确认：O2OA AE + GAN online second stage 动态异构冗余机制已经从工程路径上完成闭环；Flowable AE + local rule second stage 已通过真实服务 smoke；两者共同支撑“多平台动态二阶段机制完成阶段性验证”的收口口径，并形成了可复核的报告、CSV 和证据文件。

本阶段不能确认：GAN online 相比 rule fallback 具有稳定效果优势，不能将 O2OA GAN 外推为 Flowable GAN，也不能声称完整多平台动态异构冗余全部完成。
