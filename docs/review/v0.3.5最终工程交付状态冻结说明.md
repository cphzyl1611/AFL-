## 4. fAnoGAN 与 AE v1 最终关系

fAnoGAN candidate 已完成：

- fallback candidate；
- torch fAnoGAN-style candidate；
- 扩展样本二次评估；
- 劣于 AE v1 的原因诊断；
- 阈值重校准；
- holdout 验证。

holdout 关键结果：

| 策略 | false_accept | false_reject | accuracy |
|---|---:|---:|---:|
| rule_ae | 0 | 0 | 1.000000 |
| rule_fanogan_default | 0 | 1 | 0.970588 |
| rule_fanogan_calibrated | 0 | 0 | 1.000000 |

calibrated fAnoGAN 与 AE v1 在 holdout 上均达到 `false_accept=0,false_reject=0`，但 calibrated fAnoGAN 未优于 AE v1。

当前 recommendation：

```text
keep_ae_v1_as_primary
```

因此，AE v1 继续作为主二阶段有效性判定机制；fAnoGAN candidate 保留为后续研究增强方向。
