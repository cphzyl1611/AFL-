# 快速演示命令

## 1. 目的

本文档用于 5 分钟内快速确认仓库交付状态。

- 不用于完整复现实验；
- 完整复现见 `docs/reproduce/实验复现指南.md`；
- 本文档不启动 O2OA、Flowable、Alfresco；
- 本文档不运行长时间 fuzz。

## 2. 推荐演示顺序

1. delivery preflight；
2. 配置与 schema 校验；
3. 基础 unittest；
4. API smoke；
5. 启动轻量 API；
6. curl 查询 health / capabilities / reports；
7. fuzz submit dry_run。

## 3. 一键交付预检查

```bash
python3 scripts/delivery_preflight_check.py
```

期望输出：

```text
DELIVERY_PREFLIGHT_PASS
```

## 4. 配置与 schema 校验

```bash
python3 scripts/validate_project_configs.py
```

期望输出：

```text
VALIDATE_PROJECT_CONFIGS_PASS
```

该命令不启动 O2OA、Flowable、Alfresco，不运行长时间 fuzz，只检查 schemas、配置、seed JSON、summary evidence 和敏感信息。

## 5. 基础 unittest

```bash
python3 -m unittest discover -s tests
```

该命令只运行基础单元测试，不启动 O2OA、Flowable、Alfresco，不运行长时间 fuzz。

## 6. 轻量 API smoke

```bash
python3 scripts/smoke_api_server.py
```

期望输出：

```text
API_SMOKE_PASS
```

## 7. 手动启动轻量 API

```bash
python3 integration/api_server.py --host 127.0.0.1 --port 18081
```

说明：

- 默认只监听 `127.0.0.1`；
- 不要暴露公网；
- 另开终端执行后续 curl。

## 8. curl 查询接口

```bash
curl http://127.0.0.1:18081/health

curl http://127.0.0.1:18081/capabilities

curl http://127.0.0.1:18081/reports
```

## 9. dry_run 提交示例

```bash
curl -X POST http://127.0.0.1:18081/fuzz/submit \
  -H 'Content-Type: application/json' \
  --data '{"scenario":"nv_mab_smoke","dry_run":true}'
```

说明：

- `dry_run=true` 不运行真实 fuzz；
- 只返回白名单命令模板和任务语义；
- 不需要 O2OA token。

## 10. 结束 API 服务

- 在 API 终端按 `Ctrl+C` 停止；
- 或关闭对应终端。

## 11. 边界

- 这不是完整实验复现；
- 不代表 O2OA / Flowable / Alfresco 实验已重新运行；
- 不代表完整平台级 HTTP/RPC 网关；
- 不代表完整 MCP Server；
- 不代表完整系统级动态异构冗余；
- 不代表完整 NC_MAB 理论闭环。
