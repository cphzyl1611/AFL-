# 模糊测试模块调用说明

## 1. 基本命令

所有动作通过同一个适配器入口调用：

```bash
python3 integration/fuzz_adapter.py <action> --request-json <request.json>
```

支持动作：

- `submit`
- `query`
- `stop`
- `report_query`

查看当前可用平台 profile：

```bash
python3 integration/fuzz_adapter.py profiles
```

## 2. 任务下发 submit

O2OA 示例：

```bash
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_o2oa.json
```

Flowable 示例：

```bash
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_flowable.json
```

静态链路验证，不真正启动底层任务：

```bash
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_o2oa.json --dry-run
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_flowable.json --dry-run
```

成功返回格式：

```json
{
  "process_result": 1,
  "action": "submit",
  "task_id": "fuzz-task-xxxxxxxxxxxx"
}
```

## 3. 任务查询 query

请求示例：

```json
{
  "task_id": "fuzz-task-140a0bb94ac5"
}
```

调用：

```bash
python3 integration/fuzz_adapter.py query --request-json docs/integration/examples/fuzz_query.json
```

成功返回格式：

```json
{
  "process_result": 1,
  "action": "query",
  "task_id": "fuzz-task-140a0bb94ac5",
  "query_description": "已完成；model=ae_flowable_v2，threshold=6.3；20s pass/reject=287/65，60s pass/reject=887/181，rpc_fail_total=0"
}
```

## 4. 任务停止 stop

请求示例：

```json
{
  "task_id": "fuzz-task-140a0bb94ac5"
}
```

调用：

```bash
python3 integration/fuzz_adapter.py stop --request-json docs/integration/examples/fuzz_stop.json
```

静态停止链路验证，不发送停止信号：

```bash
python3 integration/fuzz_adapter.py stop --request-json docs/integration/examples/fuzz_stop.json --dry-run
```

成功返回格式：

```json
{
  "process_result": 1,
  "action": "stop",
  "task_id": "fuzz-task-140a0bb94ac5"
}
```

## 5. 报告查询 report_query

请求示例：

```json
{
  "task_id": "fuzz-task-140a0bb94ac5"
}
```

调用：

```bash
python3 integration/fuzz_adapter.py report_query --request-json docs/integration/examples/fuzz_report_query.json
```

只读查询已有报告，不刷新 runner 报告：

```bash
python3 integration/fuzz_adapter.py report_query --request-json docs/integration/examples/fuzz_report_query.json --no-refresh
```

成功返回格式：

```json
{
  "process_result": 1,
  "action": "report_query",
  "total_count": 1,
  "report_list": [
    {
      "task_id": "fuzz-task-140a0bb94ac5",
      "report_name": "fuzz_report_140a0bb94ac5.json",
      "download_url": "/home/dministrator/AFLplusplus/runner/tasks/140a0bb94ac5/report.json"
    }
  ]
}
```

## 6. 请求输入方式

适配器支持三种输入方式：

```bash
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_o2oa.json
```

```bash
python3 integration/fuzz_adapter.py query --json '{"task_id":"fuzz-task-140a0bb94ac5"}'
```

```bash
echo '{"task_id":"fuzz-task-140a0bb94ac5"}' | python3 integration/fuzz_adapter.py query
```

## 7. 任务 ID

适配器对外返回 `fuzz-task-<runner_task_id>` 格式。为了兼容已有 runner 数据，调用时也接受不带前缀的 runner 原始 task id。
