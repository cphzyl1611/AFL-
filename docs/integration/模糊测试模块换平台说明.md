# 模糊测试模块换平台说明

## 1. 核心原则

换平台 = 换平台 profile，不换接口。

调用方继续使用同一套动作：

- `submit`
- `query`
- `stop`
- `report_query`

只需要在 submit 请求中调整：

- `platform`
- 必要时调整 `target_endpoint`
- 必要时调整 `seed_location`

## 2. O2OA 调用

请求中的平台字段：

```json
{
  "platform": "o2oa_default"
}
```

完整示例：

```bash
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_o2oa.json
```

该 profile 会映射到：

- `runner/templates/task_ae_default.json`
- `in/o2oa_body_model_compare`
- `model_stage/manifests/dataset_manifest_156.txt`
- AE@1.0 默认模型路线

## 3. Flowable 调用

请求中的平台字段：

```json
{
  "platform": "flowable_v2"
}
```

完整示例：

```bash
python3 integration/fuzz_adapter.py submit --request-json docs/integration/examples/fuzz_submit_flowable.json
```

该 profile 会映射到：

- `runner/templates/task_ae_flowable_eval_v2.json`
- `in/flowable_process_start_dataset_v2`
- `model_stage/manifests/flowable_manifest_90.txt`
- Flowable-AE v2@6.3 最小校准验证路线

## 4. 统一调用对比

O2OA：

```json
{
  "task_name": "o2oa_fuzz_smoke_001",
  "platform": "o2oa_default",
  "target_type": "http_api",
  "target_endpoint": "cms_doc_list",
  "seed_location": "in/o2oa_body_model_compare",
  "time_budget": 60
}
```

Flowable：

```json
{
  "task_name": "flowable_v2_smoke_001",
  "platform": "flowable_v2",
  "target_type": "http_api",
  "target_endpoint": "POST /flowable-rest/service/runtime/process-instances",
  "seed_location": "in/flowable_process_start_dataset_v2",
  "time_budget": 60
}
```

两者的后续查询、停止、报告查询完全一致：

```bash
python3 integration/fuzz_adapter.py query --json '{"task_id":"fuzz-task-xxxxxxxxxxxx"}'
python3 integration/fuzz_adapter.py stop --json '{"task_id":"fuzz-task-xxxxxxxxxxxx"}'
python3 integration/fuzz_adapter.py report_query --json '{"task_id":"fuzz-task-xxxxxxxxxxxx"}'
```

## 5. Flowable 表述边界

`flowable_v2` 是第二平台最小校准验证 profile。它用于组件联调和平台校准流程验证，不把 Flowable 表述为完整第二平台 AFL++ 变异模糊测试主链。
