ROOT MISMATCH
================================================================================

C sends:
  [4-byte length][PUT /alfresco/api/.../content HTTP/1.1\nHost: ...\n\n<body>]

Scorer expects (Protocol V2):
  [4-byte length][{"scenario":"content_update","endpoint":"...","body":"<base64>"}]

Scorer recv_one() tries json.loads() on HTTP request text → JSONDecodeError
Every RPC fails at deserialization, before any model scoring.

Evidence:
1. C sends raw HTTP request bytes with no JSON wrapper
2. C does not include scenario field
3. C does not include endpoint field
4. C does not base64-encode body
5. Python sends JSON envelope with all required fields
6. Python base64-encodes body before transport
7. Scorer expects Python Protocol V2 format
8. C Protocol V1 format is incompatible
