================================================================================
TIMEOUT BEHAVIOR
================================================================================

Before timeout:
- AFL++ blocked indefinitely in recv() (line 952 after repair, ~838 pre-repair)
- Single failed RPC blocked entire fuzzing campaign for 90 seconds
- No diagnostic, no fallback, no error recovery

After timeout:
- recv() returns -1 after 2 seconds if no data received
- errno set to EAGAIN or EWOULDBLOCK
- Function returns (ok=0, score=0.0)
- Caller treats as RPC failure (NV_V_REJ_RPC_FAIL)

================================================================================
TIMEOUT CLASSIFICATION
================================================================================

When recv() times out:
1. nv_validity_rpc_score_unix() returns ok=0
2. Caller (nv_validity_check at line ~1091) receives ok=0
3. Returns NV_V_REJ_RPC_FAIL
4. common_fuzz_stuff() receives NV_V_REJ_RPC_FAIL
5. Calls nv_account_invalid(afl, NV_V_REJ_RPC_FAIL)
6. Increments afl->nv_invalid_rpc_fail_cnt
7. Skips execution (does not call fuzz_run_target)
8. Returns 0 (continue fuzzing with next input)
