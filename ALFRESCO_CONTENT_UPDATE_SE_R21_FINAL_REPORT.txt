When the runner is invoked with:
  python3 scripts/run_alfresco_bounded_feedback.py --scorer-python /path/to/conda/env/python3 ...

The harness inherits the runner's Python (base conda), NOT the --scorer-python value.

AFL command used:
  -- /home/dministrator/miniconda3/bin/python3 nv_http_harness.py

  /home/dministrator/miniconda3/envs/aflpp-se-calib-pip/bin/python3
       ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
       Conda environment with all dependencies

The base conda Python lacks required dependencies for the harness,
causing silent failures during AFL persistent-mode execution.

CORRECT LAUNCH PATTERN (for future attempts):
