BEFORE vs AFTER
================================================================================

BEFORE (R39 production):
  subprocess.Popen(
      [scorer_python, scorer_script],
      env=env,
      stdout=subprocess.PIPE,  # Output lost
      stderr=subprocess.PIPE,  # Output lost
      text=True,
  )

  Result:
  - All scorer output directed to PIPE
  - Parent never reads from PIPE
  - PIPE buffer fills (64KB typical)
  - Scorer blocks on write()
  - Output lost when process terminates
  - Exit code not captured
  - No diagnostic trail

AFTER (Step 5 repair):
  stdout_path = evidence_dir / "scorer_stdout.txt"
  stderr_path = evidence_dir / "scorer_stderr.txt"

  with open(stdout_path, "w") as out, open(stderr_path, "w") as err:
      subprocess.Popen(
          [scorer_python, scorer_script],
          env=env,
          stdout=out,  # Persisted to file
          stderr=err,  # Persisted to file
          text=True,
      )

  # Later, in stop():
  self.exit_code = self.proc.returncode

  # In artifact report:
  report["scorer_subprocess"] = {
      "exit_code": scorer_manager.exit_code,
      "stdout_path": str(scorer_manager.stdout_path),
      "stderr_path": str(scorer_manager.stderr_path),
  }

  Result:
  - All scorer output written to files
  - No PIPE blocking
  - Output persists after campaign
  - Exit code captured and recorded
  - Full diagnostic trail in evidence/
