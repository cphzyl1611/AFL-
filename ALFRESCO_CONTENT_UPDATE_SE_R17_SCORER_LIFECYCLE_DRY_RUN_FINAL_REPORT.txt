R17 identified and validated the complete scorer RPC protocol v2:

Client (nv_body_valid.py:rpc_score_unix):
  1. Construct JSON envelope:
     {
       "scenario": "<scenario>",
       "endpoint": "<endpoint_name>",
       "body": "<base64-encoded body bytes>"
     }
  2. Encode envelope as UTF-8 JSON bytes
  3. Send u32_le length prefix (4 bytes)
  4. Send envelope bytes
  5. Read response until EOF or 128-byte limit
  6. Decode response as UTF-8 text float

Server (model_stage/nv_valid_server_real.py:serve):
  1. Read u32_le length prefix
  2. Read exactly length bytes
  3. Decode JSON envelope
  4. Base64-decode body field
  5. Route by scenario (metadata_update | content_update)
  6. Extract features using scenario-specific extractor
  7. Score features through backend (sefanogan_es_reference)
  8. Send ASCII text float followed by socket close

This protocol was successfully exercised in R17 with a content_update
scenario request.
