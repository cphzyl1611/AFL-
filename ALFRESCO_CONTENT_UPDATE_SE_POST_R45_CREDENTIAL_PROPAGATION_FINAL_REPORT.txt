    pass_quoted = shlex.quote(env["ALFRESCO_PASS"])

PROPAGATION PATH:
    1. Runner script serializes credentials into AFL_TARGET_ENV
    2. AFL++ parent process receives AFL_TARGET_ENV in environment
    3. AFL++ calls extract_and_set_env() at startup (src/afl-fuzz.c:2519-2524)
    4. extract_and_set_env() parses KEY=VALUE pairs, handles quotes
    5. For each pair, calls setenv(key, val, 1) (src/afl-common.c:973)
    6. AFL++ fork server inherits these environment variables
    7. Each target execution receives them in child process environment
    8. Harness reads via os.getenv("ALFRESCO_USER") and os.getenv("ALFRESCO_PASS")

QUOTE HANDLING:
    shlex.quote() wraps values in single quotes: 'value'
    For values containing single quotes, escapes as: 'value'\''more'
    extract_and_set_env() strips outer quotes during parsing

    Example:
      shlex.quote("pass'word") → 'pass'"'"'word'
      extract_and_set_env() → pass'word (correct)

VERIFICATION: All three test dimensions PASS:
    ✓ Simple values (no spaces/quotes)

    ✓ Values with quotes and special characters
