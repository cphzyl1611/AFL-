### Architecturally Absent Files

✗ nv_probe.json  
✗ nv_state_db.json

**Architectural Reason:**

Both files are created by `nv_state_probe.update_state()`, which is called from `nv_http_harness.py` **after** an HTTP request is sent to the target. When all mutated bodies are rejected at body score validation (body_score_pass=0), zero HTTP requests are sent, making probe/state_db creation **architecturally impossible**.

**Scientific Content If Present:**

If these files existed, they would contain:
- nv_probe.json: Empty state snapshot with no HTTP response data
- nv_state_db.json: Empty state database with no coverage accumulation data
