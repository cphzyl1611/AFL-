PRIMARY ESTIMAND
--------------------------------------------------------------------------------

PRIMARY_ESTIMAND = Mean paired difference E[Δᵢ] where Δᵢ = SE_i - AE_i

ESTIMAND_DEFINITION:
  - Δᵢ = SE_security_state_new_total_i - AE_security_state_new_total_i
  - Experimental unit = one paired seed block
  - Pairing removes between-seed variance
  - Isolates model-conditioned testing behavior difference

INTERPRETATION:
  - Positive Δᵢ: SE observed more security_state_new_total than AE for that seed
  - Zero Δᵢ: Both backends observed same count for that seed
  - Negative Δᵢ: AE observed more security_state_new_total than SE for that seed

PRIMARY ANALYSIS RECOMMENDATION
--------------------------------------------------------------------------------

PRIMARY_ANALYSIS_RECOMMENDATION = Bootstrap CI + Permutation test (if hypothesis test desired)

POINT_ESTIMATE = Sample mean paired difference Δ̄
UNCERTAINTY = 95% percentile bootstrap CI (B = 10,000 resamples)
HYPOTHESIS_TEST = Permutation test (if D12 = yes) or declare 0 not in CI

RATIONALE:
  - Robust to discrete counts, ties at zero, small N
  - No normality assumptions required
  - Handles Phase-3 observed tie structure naturally

ALTERNATIVE_METHODS = Paired t-test only if N large and normality holds

DESCRIPTIVE_STATISTICS = Always report:
  - Full list of paired differences
  - Mean, median, SD, min, max
  - Proportion of ties, positive, negative
  - Visual summaries (histogram, scatter plot)
