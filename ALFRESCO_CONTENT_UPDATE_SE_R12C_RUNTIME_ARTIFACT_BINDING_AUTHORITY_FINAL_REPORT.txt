DECISION RATIONALE:

The accepted architecture EXPLICITLY designates the caller environment
as the authoritative source for SE artifact paths. This is a deliberate
design choice, not a code defect:

1. EVIDENCE FROM ACCEPTED CAMPAIGN:
   Phase-3 forensic audit explicitly states:
     "These environment variables are NOT set by the campaign runner.
      The runner inherits parent environment: env = dict(os.environ)"
   
   This behavior was SCIENTIFICALLY VALIDATED in the accepted campaign.

2. EVIDENCE FROM SCORER CONTRACT:
   load_validity_backend() fails immediately if paths are missing:
     raise ValueError("SE_REFERENCE_ARTIFACTS_REQUIRED")
   
   This is a fail-closed design that enforces caller responsibility.

3. EVIDENCE FROM TEST CONTRACTS:
   test_sefanogan_backend_wiring.py (lines 95-96) shows expected pattern:
     environment["SEFANOGAN_REFERENCE_CHECKPOINT"] = str(checkpoint)
     environment["SEFANOGAN_REFERENCE_META_PATH"] = str(metadata)
   
   Tests provision these variables BEFORE launching the orchestrator.

4. NO CODE DEFECT EXISTS:
   The orchestrator correctly inherits environment variables.
   The scorer correctly requires them and fails if absent.
   The architecture separates concerns: caller provisions artifacts,
   orchestrator provisions runtime configuration.

ARCHITECTURAL RATIONALE:

Keeping artifact paths in caller environment (not orchestrator code):
  + Supports multiple canonical models without code changes
  + Matches machine-learning deployment patterns (model registry)
  + Separates artifact management from campaign orchestration
  + Enables environment-specific artifact resolution (dev/prod)
  + Documented and validated in accepted Phase-3 campaign

R12B SUGGESTION REJECTED:

R12B suggested modifying ScorerServer.start() to inject canonical paths.
This would be an ARCHITECTURAL CHANGE that violates the accepted contract:
  - Hardcodes absolute paths into production code
  - Removes caller control over artifact resolution
  - Contradicts Phase-3 validated architecture
  - Introduces hidden dependencies on specific filesystem layout
