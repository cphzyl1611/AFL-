R39 POSTMORTEM FINDINGS (ORIGINAL)
================================================================================

The R39 postmortem investigation identified the following root cause:

1. Protocol Version Mismatch:
   - AFL++ C code sent Protocol V1: [4-byte length][raw HTTP request bytes]
   - Scorer subprocess expected Protocol V2: [4-byte length][JSON envelope]
   - Scorer's nv_valid_server_real.py called json.loads() on raw HTTP bytes
   - JSONDecodeError raised (HTTP headers cannot be parsed as JSON)

2. No Response Mechanism:
   - Scorer exception handler did not send error response
   - AFL++ waited indefinitely for response (no recv timeout)
   - Socket blocked in recv() call
   - All subsequent inputs classified as RPC failures

3. Subprocess Output Loss:
   - Scorer stdout/stderr directed to subprocess.PIPE
   - Parent process never read from PIPE
   - PIPE buffer filled and blocked scorer writes
   - All diagnostic output (traceback, error messages) lost

4. Campaign Impact:
   - First content_update input triggered the failure
   - Campaign hung indefinitely
   - No diagnostic evidence in artifact report
   - Postmortem required manual log reconstruction
