1. Added nv_base64_encode() function (lines ~777-817)
   - Standard base64 encoding with padding
   - Returns malloc'd string (caller must free)
   - Used for body encoding in Protocol V2 envelope

2. Modified nv_validity_rpc_score_unix() to send Protocol V2
   - Extracts HTTP body from full HTTP request
   - Determines scenario from endpoint path:
     * Path ends with "/content" → "content_update"
     * Otherwise → "metadata_update"
   - Base64-encodes body-only portion
   - Builds JSON envelope using cJSON:
     {
       "scenario": "content_update" | "metadata_update",
       "endpoint": "",
       "body": "<base64-encoded body>"
     }
   - Sends [4-byte length header][JSON envelope]
   - Added SO_RCVTIMEO timeout (2 seconds) - see Step 4

3. Body extraction logic
   - Finds separator (\n\n or \r\n\r\n) between headers and body
   - If no separator found, treats entire buffer as body
   - Extracted body is raw UTF-8 text for content_update
   - No JSON parsing of body (preserves raw-text semantics)

4. Scenario detection logic
   - Parses HTTP first line to extract method and path
   - Checks if path ends with "/content" (case-sensitive)
   - content_update: PUT /nodes/.../content
   - metadata_update: everything else
