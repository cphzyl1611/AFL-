ROOT CAUSE CHAIN (THREE DEFECTS IDENTIFIED)
--------------------------------------------

**DEFECT 1: Missing environment variables (ENV_VAR_NOT_PROVIDED)**
Location: scripts/run_alfresco_bounded_feedback.py, ScorerLifecycleManager.start()
Symptom: Scorer subprocess exits immediately before creating Unix socket
Root cause: ScorerLifecycleManager.start() did not inject required env vars:
  - SEFANOGAN_REFERENCE_CHECKPOINT
  - SEFANOGAN_REFERENCE_META_PATH

The scorer (model_stage/nv_valid_server_real.py:34-40) checks for these env vars
and raises ValueError if missing, causing immediate process death before socket creation.

**DEFECT 2: INPUT_DIM constant mismatch (DIMENSION_CONTRACT_VIOLATION)**
Location: model_stage/sefanogan_es_reference.py line 31
Symptom: Scorer exits with "unsupported reference model metadata" after env var fix
Root cause: INPUT_DIM = 32 but deployed metadata has input_dim = 38
Validation at line 197 fails: int(metadata["input_dim"]) != INPUT_DIM

Investigation confirmed no 32-dimensional artifacts exist in model_stage/models/.
Only sefanogan_es_reference_meta.json with input_dim=38 and feature contract
alfresco_metadata_38 (38-dimensional fixed feature vector).

**DEFECT 3: Encoder architecture mismatch (MODEL_ARCHITECTURE_MISMATCH)**
Location: model_stage/sefanogan_es_reference.py, ChannelAttentionEncoder class
Symptom: Scorer exits with "invalid reference checkpoint" after INPUT_DIM fix
Root cause: ChannelAttentionEncoder implemented with attention+projection layers
  Expected keys: attention.0.weight, attention.0.bias, attention.2.weight, etc.
  Actual checkpoint keys: net.0.weight, net.0.bias, net.2.weight, net.2.bias, net.4.weight, net.4.bias

Checkpoint inspection revealed sefanogan_gan_model.pt (SHA256: 205a6a20...856624)
was trained with simple 3-layer Encoder from sefanogan_train_gan.py:81-93:
  nn.Sequential(
    nn.Linear(input_dim, hidden_dim),
    nn.ReLU(),
    nn.Linear(hidden_dim, hidden_dim),
    nn.ReLU(),
    nn.Linear(hidden_dim, latent_dim)
  )

ChannelAttentionEncoder class was a newer architecture never trained or checkpointed.
